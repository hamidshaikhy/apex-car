# APEX — design direction

An architectural automotive showroom. The car is the focal point: full-frame campaign imagery, restrained navigation, oversized condensed typography and a quiet interface.

- Palette: carbon `#0a0b0b`, graphite `#202222`, porcelain `#f2f1ed`, aluminium `#a6a7a2`, signal orange `#ff7438`, white `#ffffff`.
- Type: Barlow Condensed 600/700 for short display headlines and large performance figures; DM Sans 400/500/600 for navigation and reading.
- Layout: cinematic full-height hero; photographic vehicle selector; light two-column collection; immersive studio invitation. Details use a full-bleed cover, three instrument-inspired figures, a visual feature explorer, and category tabs for complete technical specifications.
- Alignment: left-aligned navigation and reading content, generous gutters, consistent image edges. No italic serif headings or decorative badges.
- Interaction: vehicle changes crossfade; feature hotspots expose sourced specification details; studio drag and keyboard controls rotate the vehicle. Respect reduced motion.
- Quality: replace low-resolution previews, preserve exact trim names and measurement bases, retain keyboard access, verify desktop and mobile screenshots.

The skill's suggested red/blue palette and Playfair pairing were rejected because they do not match the supplied reference. The orange Revuelto/concrete composition determines the final palette and typography.
