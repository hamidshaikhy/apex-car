# APEX — راهنمای نسخه نمایشی

اجرا: `npm install` و سپس `npm run dev`؛ آدرس معمول `http://localhost:5173` است.

لودینگ شروع، تصاویر، فونت‌ها و مدل‌های کامل هر 12 ماشین را آماده می‌کند. لودینگ استودیو نیز منتظر آماده شدن صحنه و شیدرها می‌ماند.

برای ضبط ویدیو:

- وارد 360° Studio شوید؛ خودرو، رنگ و حالت محیط را انتخاب کنید.
- دکمه خورشید محیط سفید روز و دکمه ماه محیط تیره را فعال می‌کند.
- با کشیدن ماوس بچرخانید و با اسکرول زوم کنید. صفحه استودیو اسکرول نمی‌شود و اندازه پنجره مرورگر را می‌گیرد.
- Fullscreen را بزنید. کلید H همه کنترل‌ها و نوشته‌ها را پنهان می‌کند؛ با H، Escape یا دکمهٔ همیشه‌نمایان «نمایش کنترل‌ها» برگردید.
- برای حرکت پیوسته، Auto rotate را فعال کنید.

اولویت این نسخه کیفیت تصویر است. مدل‌های کامل حفظ شده‌اند؛ مدل Mustang حدود 51 مگابایت است. صحنه از استیج دایره‌ای، بازتاب، سایه، متریال بدنه، شیشه دودی و رندر با وضوح دوبرابر استفاده می‌کند.

راهنمای تصویری پروژه و اجرای نصب از ابتدا در [README اصلی](README.md) آمده است. برای تازه‌کردن عکس‌های آن، پس از اجرای سایت با `npm run dev`، دستور `node scripts/capture-readme.mjs` را اجرا کنید.

بررسی: `npm run build` و `npm test`.
